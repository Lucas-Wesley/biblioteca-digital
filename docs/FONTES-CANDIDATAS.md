# Fontes candidatas

Sites com livros em português, para avaliar um a um se dá para virar adaptador (ver
[`FONTES.md`](FONTES.md)). Lista feita em **05/11/2026**. Só entram sites em português e no ar.

**Situação** é o que o site respondeu quando conferido em 05/11/2026:
- **No ar:** respondeu normalmente.
- **Cloudflare:** respondeu com a verificação anti-robô do Cloudflare, sinal de que está no ar, mas
  falta abrir no navegador para confirmar. Para extrair, essa verificação é um obstáculo a mais.
